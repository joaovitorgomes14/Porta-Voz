DIA 25/03  PASTAS

- Server.js = Vai ser onde a aplicação começa. *Sobe o servidor, configura o express, conecta tudo.*

- ROUTES vão ser as rotas rotas da minha API que vao definir os caminhos.

- CONTROLLERS vai ser aquilo que recebe as requisições e decide o que fazer.

- SERVICES vai ser onde as regras serão validadas os dados vao ser processados e vai decidir o que pode e o que nao pode.

- DATABASES acesso ao banco. vai ser a chamada que conecta o banco de dados.

*routes - user - controller - service - databases.*

- psql -U postgres -d porta-voz  - comando para entrar no banco de dados novamente.
- \q -  comando para quitar do banco de dados.
