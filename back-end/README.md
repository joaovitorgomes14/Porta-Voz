# Nome do Projeto

Chatbot desenvolvido para facilitar o registro de reclamações, solicitações e demandas dos cidadãos para a prefeitura.

---

## Sobre o Projeto

O projeto foi desenvolvido com o objetivo de melhorar a comunicação entre a prefeitura e os cidadãos, oferecendo uma forma mais prática e acessível para o registro de reclamações, solicitações e demandas da população.

Com o grande volume de solicitações recebidas diariamente, muitas prefeituras enfrentam dificuldades para organizar, acompanhar e atender todas as demandas de maneira eficiente. Pensando nisso, o chatbot foi criado para facilitar tanto o processo de coleta dessas informações quanto o acompanhamento das solicitações pelos próprios usuários.

O sistema tem como público-alvo os cidadãos que desejam registrar demandas relacionadas ao município e a equipe responsável pelo atendimento e gerenciamento dessas solicitações. Além de otimizar o processo de comunicação, o projeto também busca aproximar a população do poder público, tornando o atendimento mais organizado, transparente e acessível.

---

## 🚀 Funcionalidades

- [x] Registro de reclamações e demandas da população.
- [x] Atendimento automatizado por meio de chatbot.
- [x] Coleta de informações do cidadão para abertura da solicitação.
- [x] Registro de endereço relacionado à demanda.
- [x] Validação básica de dados informados pelo usuário.
- [x] Acompanhamento do status das solicitações.
- [x] Organização das demandas registradas.
- [x] Armazenamento das informações em banco de dados.
- [x] Interface simples e acessível para facilitar o uso pela população.
- [x] Comunicação entre cidadãos e prefeitura de forma centralizada.
- [x] Histórico de solicitações realizadas pelos usuários.
- [x] Fluxo de atendimento automatizado utilizando estados de conversa
