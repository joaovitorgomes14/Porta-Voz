## ⚙️ Instalação

### Pré-requisitos

- Node.js
- Git
- NPM ou Yarn

### Clone o repositório

```bash
git clone https://github.com/seuusuario/seuprojeto.git
```

### Entre na pasta

```bash
cd seuprojeto
```

### Instale as dependências

```bash
npm install
```

### Rode o projeto

```bash
npm run dev
```
